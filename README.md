# design-system_stats

Хранилище статистики проверок Apollo и итоговой аналитики.

Репозиторий содержит отчёты проверок и исторические аналитические срезы.
Каталоги дизайн-системы, индексы,
паттерны и agentic-контракты здесь не хранятся.

## Структура

```text
apollo/
  analytics/
    v3-2026-10-29/            # итоговая аналитика V3 и компактные агрегаты
  stats/
    <figma-user>/
      dd-mm-yyyy/
        <figma-user>_dd-mm-yyyy_hh-mm-ss.json
        <figma-user>_dd-mm-yyyy_hh-mm-ss_agent.json
        <figma-user>_dd-mm-yyyy_hh-mm-ss_customizations-wip.json
```

## Аналитика Apollo V3

[Итоговый анализ за 10.06–29.10.2026](apollo/analytics/v3-2026-10-29/README.md)
охватывает 1 862 проверки, 47 участников и 478 974 наблюдения компонентов.
[Детализация](apollo/analytics/v3-2026-10-29/DETAILS.md) содержит участников,
компоненты, причины кастомизации и категории ошибок.

Исходные 3 639 JSON-отчётов V3 объёмом 1,23 ГиБ удалены из текущей ветки.
Их пути и контрольные суммы сохранены в
[manifest](apollo/analytics/v3-2026-10-29/source-manifest.json), исходники
доступны в Git-ревизии `739e7f52e1206b9b71d8445e65c1408d320af7bd`.
Архив аналитического среза оставлен локально вне репозитория.
История Git не переписывалась.

`apollo/stats/` остаётся каталогом для новых отчётов. Историческая аналитика
V3 хранится отдельно: её оценки и категории нельзя автоматически смешивать
с результатами следующих версий Apollo.

## Типы отчётов

- `*.json` — полный технический отчёт Apollo для отладки аудита.
- `*_agent.json` — компактный отчёт для отправки в корпоративного агента.
- `*_customizations-wip.json` — необработанные факты `effective baseline → actual`
  для отладки агентской интерпретации кастомизаций.
- `*_predicates.json` — отдельный предикатный контур V3, связанный с исходной проверкой.

Это исторические виды V3. Состав файлов и схема новых версий определяются
их отправителем; число JSON-файлов не равно числу проверок.

## Публикация

Production-сборка Apollo не пишет в репозиторий напрямую. Плагин отправляет
отчёт в Supabase Edge Function `apollo-stats`, а функция уже публикует JSON в
этот репозиторий.

При переезде с `design-system_ab` нужно обновить настройки Edge Function:

- целевой GitHub repo: `Ackedze/design-system_stats`;
- целевая ветка: `main`;
- путь внутри repo: `apollo/stats`.
